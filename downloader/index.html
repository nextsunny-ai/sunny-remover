Sunny Downloader

영상 링크를 목록에 모아두고 MP4·원본 화질·MP3로 받는 광고 없는 다운로더

⬇ 다운로드 (맥·윈도우 공용, 160KB)

v5 · 2026-11-25 · 압축 하나에 맥과 윈도우 설치 파일이 모두 들어 있습니다.

맥 설치 처음 한 번만

  1. 압축을 풀고 영상다운로더 폴더를 문서 폴더로 옮깁니다. (다운로드 폴더에 두었다 지우면 앱이 안 열립니다)
  2. 터미널을 엽니다. command + 스페이스 → "터미널" → 엔터
  3. bash 를 치고 스페이스 한 칸 띄웁니다.
  4. 폴더 안 처음설치_맥.command 파일을 터미널 창에 끌어다 놓고 엔터.
  5. 5~10분 뒤 "설치 끝"이 나오면 바탕화면에 Sunny Downloader 앱이 생깁니다.

비밀번호를 물으면 맥 로그인 비밀번호를 칩니다. 칠 때 화면에 아무것도 안 보이는 게 정상입니다.
파일을 더블클릭하면 맥 보안이 막습니다. 바이러스가 아니라 맥 기본 기능이라, 위처럼 터미널로 실행하면 됩니다.

윈도우 설치 처음 한 번만

  1. 압축을 계속 둘 폴더에 풉니다.
  2. 처음설치_윈도우.bat 더블클릭. 파이썬이 없으면 자동으로 설치합니다.
  3. 바탕화면에 Sunny Downloader 아이콘이 생깁니다.

쓰는 법

  1. 브라우저에서 링크를 복사 → 복사한 링크 붙여넣기 (단축키도 됨). 여러 개를 계속 쌓아둘 수 있고, 껐다 켜도 목록이 남습니다.
  2. 화질을 고르고 목록 다운로드 → 대기·실패 항목만 차례로 받습니다.
  3. 파일 이름은 원래 영상 제목 그대로 저장됩니다.
  4. 다운로드 기록 버튼 = 받은 날짜·제목·원본 링크가 쌓인 엑셀(csv). 레퍼런스 출처 정리용.
  5. 갑자기 안 받아지면 안 받아질 때: 엔진 업데이트 → 프로그램을 껐다 켭니다.
