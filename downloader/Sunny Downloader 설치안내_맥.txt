Sunny Downloader — 맥 설치 안내
================================

※ 받은 파일을 더블클릭하면 맥이 "확인되지 않은 개발자"라며 막습니다.
   바이러스가 아니라 맥 기본 보안입니다. 아래처럼 터미널로 실행하면 됩니다.


[처음 설치]
1. SunnyDownloader_Mac.zip 을 더블클릭해서 풉니다.
2. 생긴 '영상다운로더' 폴더를 '문서' 폴더로 옮깁니다.
   (다운로드 폴더에 두었다가 지우면 앱이 안 열립니다)
3. 터미널을 엽니다: command + 스페이스 → "터미널" → 엔터
4. bash 를 치고 스페이스 한 칸 띄웁니다.
5. 폴더 안 '처음설치_맥.command' 를 터미널 창에 끌어다 놓고 엔터.
6. 5~10분 뒤 "설치 끝"이 나오면 바탕화면에 'Sunny Downloader' 앱이 생깁니다.
   - "Password:" 가 나오면 맥 로그인 비밀번호 → 엔터 (칠 때 안 보이는 게 정상)
   - "Press RETURN" 이 나오면 엔터

클로드 코드를 쓰시면: "이 폴더의 처음설치_맥.command 를 bash로 실행해줘"


[앱이 처음 안 열릴 때]
- 앱 우클릭 → 열기 → 열기
- 또는 사과 메뉴 → 시스템 설정 → 개인정보 보호 및 보안 → [그래도 열기]


[쓰는 법]
1. 브라우저에서 링크 복사(command+C) → 맨 위 '링크' 칸에 command+V → 엔터
   여러 개를 쌓아둘 수 있고, 껐다 켜도 목록이 남습니다.
2. 화질 고르기 → '목록 다운로드'
   - 편집용 1080p MP4 (추천)
   - 최고화질 원본 MP4 (4K·8K 그대로, 편집툴에 따라 안 열릴 수 있음)
   - 원본 MP4 · 프리미어 호환 변환 (느림, 어디서나 열림)
   - 최고화질 원본 MKV / 음악만 MP3
3. '다운로드 기록' = 받은 날짜·제목·원본 링크가 쌓인 엑셀(csv)
4. 안 받아지면 '안 받아질 때: 엔진 업데이트' → 껐다 켜기


[로그인이 필요한 영상 (인스타그램·링크드인·비공개 비메오 등)]
화질 옆 '로그인 필요한 영상'에서 평소 그 사이트에 로그인해 둔 브라우저(크롬·사파리 등)를 고르세요.
처음에 맥이 '키체인 접근 허용'을 물으면 허용을 누릅니다. 안 되면 '쿠키 파일' 방식을 쓰세요
(크롬 확장 'Get cookies.txt LOCALLY' → Export → 저장한 파일 선택).
※ 복제 방지(DRM)가 걸린 영상은 받을 수 없습니다.

[새 버전]
새 버전이 나오면 프로그램을 켤 때 위쪽에 주황색 공지가 뜹니다.
'지금 업데이트' 를 누르면 알아서 바꾸고 다시 켜집니다.
